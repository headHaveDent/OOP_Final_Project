# Computer Network Troubleshoot Assistance

## Need at least Python 3.14.6  (other versions untested)

## Program to troubleshoot network problems offline

To run the program, use the main.py file

In the Help page, use the search bar or scroll to find the problem, and selecting a particular network problem will print the descriptions including the symptoms, causes and solutions

Problem can be also reported by clicking the report button under the search bar with the problem selected with real-time data. It will logged in in history log that can be viewed in the History Log page.

Settings includes text size, dark mode, and changing username to customize the looks of it. It also has the option to clear the files

History Log is stored in the problemlog.jsonl, while username is at username.json
